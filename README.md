# Beslan Cars — лендинг автозапчастей (beslancars.ru)

Статический сайт для GitHub Pages: автозапчасти в Беслане с доставкой по Северной Осетии.
Без сборки и зависимостей — просто HTML/CSS/JS.

## Публикация на GitHub Pages
1. Settings → Pages → Source: **Deploy from a branch** → branch `main` (или `master`) → folder `/ (root)` → Save.
2. Файл `.nojekyll` в корне обязателен (уже есть) — отключает обработку Jekyll.
3. Файл `CNAME` указывает домен `beslancars.ru`.

## Подключение домена beslancars.ru
У регистратора / в DNS-панели домена настройте записи:
- `A` → `185.199.108.153`
- `A` → `185.199.109.153`
- `A` → `185.199.110.153`
- `A` → `185.199.111.153`
- (опционально) `CNAME` для `www` → `имя-аккаунта.github.io`

В настройках GitHub Pages включите **Enforce HTTPS** после выпуска сертификата.

## Что осталось добавить после запуска
- [ ] ID Яндекс.Метрики и Google Analytics — раскомментировать блоки в `<head>` index.html (и при необходимости в других страницах).
- [ ] Фото ПВЗ → положить файл `assets/images/pvz-photo.jpg` — оно появится на сайте автоматически.
- [ ] Картинку для соцсетей → `assets/images/og-image.jpg` (1200×630).
- [ ] Приём заявок: создать Telegram-бота (@BotFather) и вписать `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в начале файла `js/main.js`. Пока бот не настроен, форма открывает письмо на почту.

## Полезные файлы
| Файл | Назначение |
|---|---|
| index.html | Главная страница |
| blog.html + blog/*.html | Блог (SEO-статьи) |
| privacy.html | Политика конфиденциальности (noindex) |
| spasibo.html | Страница спасибо после заявки (noindex) |
| sitemap.xml, robots.txt | Для поисковых систем |
| css/style.css | Стили, фирменные цвета (тёмно-синий + оранжевый) |
| js/main.js | Меню, формы, отзывы, маска телефона |

## Как добавить отзыв
Откройте `js/main.js`, найдите массив `REVIEWS`, добавьте объект:
```js
{ name: 'Имя', city: 'Город', rating: 5, text: 'Текст отзыва' },
```
Сохраните и закоммитьте — отзыв появится на сайте.
